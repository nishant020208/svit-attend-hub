**SVIT Attend Hub** is a premium, enterprise-grade College Management System (ERP) designed for Sardar Vallabhbhai Patel Institute of Technology. It streamlines attendance tracking, library management, and academic coordination through a modern, mobile-first web interface.

---

## ✨ Key Features

### 🏢 Multi-Role Ecosystem
- **Admin Dashboard**: Full control over students, teachers, and system configurations.
- **Teacher Portal**: Manage attendance, homework, and view class performance reports.
- **Student Hub**: Track personal attendance, view results, and access study materials.
- **Parent Portal**: Monitor student progress, attendance, and receive institutional updates.
- **Librarian Suite**: Efficient book tracking with QR-based check-in/out.

### 📊 Smart Management
- **QR Attendance**: Real-time attendance marking using dynamic QR code scanning.
- **Library QR System**: Instant book issuing and returning via integrated QR scanner.
- **Academic Suite**: Centralized management of Timetables, Homework, and Results.
- **Leave Management**: Structured workflow for student and staff leave applications.

### 📱 Advanced Technology
- **PWA Support**: Install the app directly on any device for a native-like experience.
- **Real-time Analytics**: Interactive charts and reports powered by Recharts.
- **Secure Auth**: Robust authentication and data security via Supabase.
- **Responsive Design**: Seamless experience across mobile, tablet, and desktop.

## 🛠️ Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+) or [Bun](https://bun.sh/)
- [Supabase](https://supabase.com/) Project

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/nishant020208/svit-attend-hub.git
   cd svit-attend-hub
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   bun install
   ```

3. **Environment Setup**
   Create a `.env` file in the root directory:
   ```env
   VITE_SUPABASE_URL=your_supabase_url
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```

4. **Start Development Server**
   ```bash
   npm run dev
   # or
   bun dev
   ```
